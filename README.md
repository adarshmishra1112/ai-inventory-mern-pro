# 🚀 AI Inventory Pro — Enterprise MERN SaaS (POS & 18% GST)

An enterprise-grade AI-powered Inventory Management & Omnichannel POS system built on the MERN stack.

## ✨ Key Features
- **Predictive AI Demand Forecasting:** 7-day sales velocity & automated restock recommendations.
- **Barcode POS Scanner & 18% GST Billing:** Instant SKU barcode lookup with automated 9% CGST + 9% SGST invoice generation.
- **Omnichannel Sync:** Unified stock tracking across Amazon India, Flipkart, Shopify D2C, and Offline POS.
- **AI Copilot & Automated Alerts:** Low-stock risk detection and one-click supplier restock workflows.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Custom Dark SaaS UI, Data Visualization Charts
- **Backend:** Node.js, Express.js, JWT Authentication
- **Database:** MongoDB
